## Backend — Render

### Configuration (`render.yaml`)

```yaml
services:
  - type: web
    name: biometric-blackhole
    runtime: python
    plan: free
    buildCommand: pip install -r backend/requirements.txt
    startCommand: cd backend && python api.py
    healthCheckPath: /api/health
    envVars:
      - key: PYTHON_VERSION
        value: 3.11.0
      - key: PORT
        value: 5000
      - key: JWT_SECRET_KEY
        generateValue: true
      - key: PASSWORD_SALT
        generateValue: true
      - key: MONGODB_URI
        value: mongodb+srv://...   # ⚠️ HARDCODED — rotate immediately
```

### Deploy Steps

1. Connect GitHub repo to Render
2. Render reads `render.yaml` from repo root
3. `JWT_SECRET_KEY` and `PASSWORD_SALT` auto-generated by Render
4. Push to `main` triggers rebuild

### Production URL

`https://biometric-blackhole.onrender.com`

### Health Check

```bash
curl https://biometric-blackhole.onrender.com/api/health
# Expected: {"status": "healthy", "message": "API is running"}
```

### Known Issues

- **Flask dev server** — `python api.py` uses Werkzeug, not Gunicorn
- **Free tier cold starts** — 30–60 second delay after idle
- **Hardcoded MONGODB_URI** in render.yaml — security risk

## Frontend — Vercel

- **Framework:** Vite

Config file: `frontend/vercel.json`

### Environment Variables

Set in Vercel dashboard:


### Production URL

`https://biometric-blackhole.vercel.app`

## Database — MongoDB Atlas

Manual setup — not managed by Render/Vercel.

| Setting | Value |
|---------|-------|
| Database name | `biometric_attendance` (env: `MONGODB_DB_NAME`) |
| Connection | `MONGODB_URI` env var |
| Indexes | Created on startup via `init_db()` in `database.py` |

Steps:
1. Create MongoDB Atlas cluster
2. Create database user
3. Whitelist IP `0.0.0.0/0` (required for Render free tier)
4. Set `MONGODB_URI` in Render dashboard (remove hardcoded value from render.yaml)
