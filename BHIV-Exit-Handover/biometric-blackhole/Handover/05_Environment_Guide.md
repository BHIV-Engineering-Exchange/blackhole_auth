## MongoDB Atlas Setup

1. Create cluster at [cloud.mongodb.com](https://cloud.mongodb.com)
2. Create database user with read/write access
3. IP whitelist: `0.0.0.0/0` (required for Render free tier)
4. Copy connection string → `MONGODB_URI`
5. Collections and indexes created automatically on first `init_db()` call
